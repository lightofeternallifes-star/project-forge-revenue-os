# Reusable Components

| Component | Reuse contract |
| --- | --- |
| Employee Definition | Canonical source for identity, role, assignment, and scope |
| Artifact Manifest | Lists required output records and template versions |
| Token Registry | Defines allowed template variables and types |
| Lifecycle State Machine | Defines legal stages and transitions |
| Evidence Manifest | Links claims, approvals, signatures, and outcomes to evidence |
| Quality Gate Runner | Applies deterministic package checks |
| Approval Matrix | Resolves responsible department, manager, executive, and audit approvers |
| Registry Writer | Appends identity, status, timeline, and version records |
| Branding Resolver | Returns canonical logo and brand references without copying assets |
| Archive Manifest | Seals generated history and retention decisions |
