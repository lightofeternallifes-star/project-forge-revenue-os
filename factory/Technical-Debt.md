# Technical Debt

1. The repository currently contains documentation specifications rather than a runtime factory.
2. Existing employee records are Markdown and require a future structured persistence contract.
3. Template rendering, artifact checksums, signatures, and registry writes are not yet implemented.
4. Corporate brand asset URIs must be supplied by the official Carriersfy AI brand system before rendering.
5. Retention schedules require legal and compliance approval for each record class.

These constraints are explicit design debt and do not weaken the historical employee record.
