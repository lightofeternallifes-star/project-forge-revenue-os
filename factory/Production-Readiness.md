# Production Readiness

## Ready

- Lifecycle stages and ownership are defined.
- Required employee records are inventoried.
- Templates are parameterized and provider agnostic.
- Quality gates and evidence obligations are explicit.
- Branding is centralized by reference.

## Required Before Runtime Automation

- Implement a signed canonical definition store.
- Implement idempotent generation jobs and durable event delivery.
- Implement authorization, secrets isolation, and tenant boundaries.
- Implement artifact storage with retention and legal hold support.
- Build validation fixtures for multiple departments and lifecycle outcomes.
- Complete security, compliance, and disaster-recovery review.
