# Branding Module

## Purpose

Ensure every generated employee artifact references the canonical Carriersfy AI brand system.

## Responsibilities

Resolve approved logo references, colors, typography, naming, and usage policy without copying or modifying assets.

## Inputs

Canonical branding directory, artifact type, rendering target, and policy version.

## Outputs

Brand reference block, compliance result, asset URI references, and escalation on missing authority.

## Future APIs

`resolveBrandReferences(artifactType)`, `validateBrandUsage(artifactId)`, `getCanonicalAsset(assetId)`.

## Dependencies

Canonical Carriersfy AI brand system, Templates, Quality Gates, and Audit.
