# Screen Inventory

| Screen | Route key | Primary data |
| --- | --- | --- |
| Executive Dashboard | `dashboard` | Metrics, alerts, factory and registry health |
| Employee Registry | `employees` | Searchable canonical employee list |
| Employee Profile | `employee/:id` | Complete employee record and timeline |
| Mission Center | `missions` | Mission status, evidence, performance |
| Certification Center | `certifications` | Certificates, diplomas, reviews |
| Promotion Center | `promotions` | Promotion proposals and history |
| Hall of Fame | `hall-of-fame` | Recognized employee records |
| Factory | `factory` | Templates, generators, lifecycle, queue |
| Executive Audit | `audit` | Quality gates and issues |
| Settings | `settings` | Workspace and access configuration |
