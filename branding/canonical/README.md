# Canonical Corporate Branding

This directory is the single reference point for Carriersfy AI corporate branding used by Digital Employee records.

The official company logo remains the existing corporate asset. This repository does not duplicate, redraw, or invent logo artwork. Brand colors and typography are controlled by the official corporate source of truth; local files record policy and references only.

All future employee documents must reference this directory and the official corporate assets rather than embedding independent branding decisions.
