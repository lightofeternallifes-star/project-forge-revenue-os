# LinkedIn Provider

## Purpose
Reserve an adapter boundary for authorized LinkedIn capabilities.

## Responsibilities
Isolate approved profile, company, or engagement capabilities without scraping or bypassing access controls.

## Inputs
Provider-neutral requests, authorization context, and future managed credentials.

## Outputs
Normalized observations, consent metadata, capability status, and typed errors.

## Future APIs
Only documented and authorized capability adapters with policy enforcement.

## Dependencies
Provider contracts, policy knowledge, and shared types.
