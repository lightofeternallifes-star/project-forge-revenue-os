# Explee Provider

## Purpose
Reserve an adapter boundary for Explee as one optional external provider.

## Responsibilities
Map authorized capabilities into provider-neutral contracts, normalize responses, preserve provenance, and translate errors.

## Inputs
Provider-neutral requests and future managed credentials.

## Outputs
Normalized results, capability metadata, provenance, and typed errors.

## Future APIs
Capability-specific adapters after authorized requirements are documented.

## Dependencies
Provider contracts and shared types; no Explee-specific assumptions may cross into core or intelligence.
