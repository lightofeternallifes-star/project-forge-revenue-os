# Apollo Provider

## Purpose
Reserve an adapter boundary for Apollo prospect and company data capabilities.

## Responsibilities
Normalize authorized search, enrichment, and metadata responses behind provider-neutral ports.

## Inputs
Discovery or enrichment requests and future managed credentials.

## Outputs
Company or contact observations, provenance, capability metadata, and typed errors.

## Future APIs
Search and enrichment adapters after contract tests exist.

## Dependencies
Provider contracts and shared types only.
