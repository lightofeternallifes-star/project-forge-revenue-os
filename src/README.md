# Revenue OS Platform Foundation

This directory contains the provider-agnostic foundation for PROJECT FORGE Revenue OS™. Mission 004 establishes architecture boundaries and future implementation contracts; it intentionally contains no provider API calls, business logic, UI, or automations.

## Dependency Direction

Core coordinates workflows and events. Intelligence defines domain capabilities. Providers adapt external systems behind contracts. Employees describe bounded Digital Employee roles. Automation owns future operational capabilities. Types and knowledge provide shared contracts and governed context.

Modules depend on stable interfaces and domain types, never on a concrete external provider.
