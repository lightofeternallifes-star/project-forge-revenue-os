# Scoring Intelligence

## Purpose
Define explainable, versioned scoring contracts for qualification and prioritization.

## Responsibilities
Represent score inputs, weights or model references, thresholds, explanations, calibration, and review state.

## Inputs
Company, contact, ICP, enrichment, research, and outcome features.

## Outputs
Scores, factor explanations, confidence, model or rule version, and score-change events.

## Future APIs
score, explain, calibrate, and compareVersions.

## Dependencies
Shared types, intelligence records, knowledge policy, memory, and model-neutral inference ports.
