# Memory

## Purpose
Define governed access to short-term execution state and durable revenue context.

## Responsibilities
Specify scopes, retention, provenance, freshness, access policy, conflict handling, and retrieval contracts.

## Inputs
Memory queries, facts, observations, workflow context, tenant scope, and retention policy.

## Outputs
Attributed memory records, freshness metadata, conflict sets, acknowledgements, and access decisions.

## Future APIs
read, write, search, invalidate, and explainProvenance.

## Dependencies
Shared types and knowledge governance; storage is injected behind ports.
