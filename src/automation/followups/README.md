# Follow-up Automation

## Purpose
Define future stateful follow-up plans with explicit stop and escalation rules.

## Responsibilities
Represent sequence state, timing, branching, suppression, timezones, retries, approvals, and cancellation.

## Inputs
Conversation state, outreach outcomes, policy, calendar context, and approved workflow definitions.

## Outputs
Scheduled proposals, transition events, stop decisions, escalation requests, and audit records.

## Future APIs
startSequence, advance, pause, stop, and explainNextStep.

## Dependencies
Core workflows and events, memory, outreach, intelligence, policy knowledge, and scheduling ports.
