# Analytics Automation

## Purpose
Define future collection and computation boundaries for revenue analytics.

## Responsibilities
Specify event-derived metrics, attribution, funnel states, quality indicators, experiment dimensions, and freshness expectations.

## Inputs
Versioned events, workflow outcomes, CRM state, appointments, and approved metric definitions.

## Outputs
Metric observations, aggregates, attribution records, anomaly signals, and learning inputs.

## Future APIs
defineMetric, compute, attribute, detectAnomaly, and getFunnel.

## Dependencies
Core events, knowledge metric definitions, CRM and workflow contracts, and future storage ports.
