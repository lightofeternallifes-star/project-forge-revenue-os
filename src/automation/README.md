Reserve bounded operational capabilities for a future runtime after intelligence and policy contracts are validated.

Define outreach, follow-up, CRM, and analytics boundaries without executing actions in Mission 004.

Action proposals, scheduled work, state transitions, outcome events, and audit records.

Capability-specific ports for planning, scheduling, execution, cancellation, and outcome capture.

## Dependencies
Core runtime, intelligence, employees, knowledge policies, events, and provider adapters.
