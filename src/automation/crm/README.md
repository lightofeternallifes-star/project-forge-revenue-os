# CRM Automation

## Purpose
Define future governed CRM synchronization and handoff capabilities.

## Responsibilities
Represent record mappings, ownership, lifecycle state, proposed changes, conflict handling, and auditability.

## Inputs
Normalized intelligence, workflow events, appointment outcomes, mapping policy, and provider capabilities.

## Outputs
Change proposals, sync events, conflict records, task assignments, and handoff receipts.

## Future APIs
proposeChange, approveChange, sync, reconcile, and handoff.

## Dependencies
Core events, intelligence, memory, knowledge policy, and provider-neutral CRM ports.
