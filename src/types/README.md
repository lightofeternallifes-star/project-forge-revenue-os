# Shared Types

## Purpose
Define stable, provider-neutral contracts shared across the Revenue OS architecture.

## Responsibilities
Own entity identifiers, tenant scope, provenance, confidence, events, commands, errors, policies, and capability contracts.

## Inputs
Domain requirements and approved architectural decisions.

## Outputs
Versioned schemas for companies, contacts, intelligence, workflows, events, employees, and providers.

## Future APIs
Schema packages and compatibility checks for public and internal contracts.

## Dependencies
No runtime dependencies. Types must not import concrete providers or application modules.
